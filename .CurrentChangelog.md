### 0.17.2-rc.4 (2026-09-23)

Features:

* [CMake]
  * Used the system blake3 library when it is available, and fell back to the vendored copy otherwise. (#5339)
    * Set `-DCMAKE_DISABLE_FIND_PACKAGE_blake3=ON` to force the vendored copy.
* [WASI-NN]
  * Upgraded the llama.cpp dependency of the GGML backend to v0.4.1. (#5188, #5356)
    * Added the `load-mode` metadata (`auto`, `none`, `mmap`, `mlock`, `mmap+mlock`, or `dio`), and mapped the legacy `use-mmap` and `use-mlock` metadata onto it.

Fixed issues:

* [Loader]
  * Loaded the native shared-library WASM only in the AOT run mode. (#5292)
  * Bound-checked the symbol offsets of the AOT custom sections. (#5255)
  * Checked the size bound before allocating the read buffer, so that a crafted length no longer allocates gigabytes before the loading fails. (#5325)
* [Executor]
  * Erased the exception payload on `catch_all` and `catch_all_ref` in the interpreter. (#5202)
  * Dropped the stale `try_table` handlers at branch time, which caused an out-of-bounds write. (#5252)
  * Corrected the `return_call` continuation of the tail calls into the host functions. (#5286)
  * Typed the null values of the abstract reference type locals with the bottom type, which corrected `ref.test` and `ref.cast` on them against the nullable concrete types. (#5347)
  * Trapped with the new `CallStackExhausted` error (`0x041B`) when the interpreter stack exceeds 8 MiB, instead of growing until the process runs out of memory. (#5377)
* [AOT]
  * Bound-checked the memory64 loads and stores. (#5282)
* [LLVM]
  * Mapped the `Os` and `Oz` optimization levels to `O2` with the size attributes on LLVM 23, whose default pass pipeline no longer supports them. (#5328)
* [Component Model]
  * Grew the component index space on the exports to match the validator. (#5256)
* [WASI]
  * Enforced the read-only preopen rights, and attenuated the rights of the child descriptors to the ones that their parent can pass on. (#5340)
  * Validated the guest output buffer bounds of `sock_getaddrinfo` before writing the resolver results. (#5344)
  * Skipped `epoll_wait` in `poll_oneoff` on Linux when no event is subscribed. (#5364)
  * Corrected the `poll_oneoff` timeouts and the `select` error handling on Windows. (#5365)
  * Mapped the Windows socket and `getaddrinfo` errors to the matching WASI error codes, so that the refused, reset, and timed-out connections are no longer reported as `ENOSYS`. (#5373)
* [WASI-NN]
  * Validated the metadata of the GGML and BitNet backends, and rejected the values which overflow the fixed-size buffers or make llama.cpp throw or abort, such as `tensor-split`, `batch-size`, `ubatch-size`, `n-cpu-moe`, `cache-type-k`, `cache-type-v`, `pooling-type`, `mirostat`, `threads`, and `threads-batch`. (#4916, #5356)
  * Applied the metadata atomically in the GGML and BitNet backends, so that a rejected option rolls back the whole metadata object. (#4916, #5356)
  * Applied the `embd-normalize` metadata in the GGML and BitNet backends, and the load-time `threads-batch` metadata in the GGML backend, which had no effect before. (#4916, #5356)
  * Rebuilt the MoE tensor overrides of the GGML backend on every metadata pass, so that the later `cpu-moe` and `n-cpu-moe` changes take effect. (#5356)
  * Preserved the other load-mode flag when only one of the legacy `use-mmap` and `use-mlock` metadata is updated in the GGML backend. (#5188)
  * Rejected the prompts which the tokenizer cannot decode with `InvalidArgument` in the GGML and BitNet backends, instead of terminating the process. (#4916)
  * Replaced the hardcoded output size of the RPC `get_output` and `get_output_single` with the guest buffer size, which is bounded to 16 MiB. (#5031)
  * Pinned the OpenVINO CPU inference precision to f32, so that the results no longer depend on the host CPU. (#5348)
* [Plugin]
  * Required OpenCV 5 for the `wasmedge_opencvmini` plug-in, and limited its CI and release builds to macOS arm64. (#5280)
* [Common]
  * Corrected the display strings and the comments in `enum.inc`. (#5241)
* [Misc]
  * Added the missing `PropComponent` in the driver fuzzer. (#5035)
  * Made the sources compile as C++20. (#5338)
